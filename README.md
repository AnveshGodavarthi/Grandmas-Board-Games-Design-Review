# Grandma's Board Games — Design Review

This public repository is the browser-accessible review surface for UI/UX brainstorming, visual alternatives, interactive comparisons, and storyboards for Grandma's Board Games.

- [Open the live review surface](https://anveshgodavarthi.github.io/Grandmas-Board-Games-Design-Review/)
- App implementation remains in the private `AnveshGodavarthi/Great-Indian-Board-Games` repository.
- Only approved decisions move into the app's source-of-truth design documents.
- Do not publish private code, secrets, internal data, or implementation-only assets here.

The first checkpoint compares gameplay-screen compositions. Future review topics should be added to this same public surface so the URL remains stable.
