Expo foundation

Cinematic Memory Home travel is working

A saved player can enter the painted veranda or courtyard, switch rooms by button or swipe, see Grandma's state change, and view the correct game-specific board preview. Standard motion uses a layered 800 ms cinematic snap; reduced motion changes rooms immediately.

Honest product boundary

This is a functioning application foundation, but it is not a playable match yet. Match Setup, lobby, intro formation, turns, results, and multiplayer remain ahead.

What works now

These are implemented capabilities in the private application branch, not only design concepts.

1

Saved player profile

Required name, one of eight ready-made characters, local persistence, profile editing, and returning-player restoration.

2

Authored Memory Home

Original painted veranda and courtyard plates, separate foreground depth, swipe navigation, and accessible scene descriptions.

3

Shared game geometry

The 5×5 Ashta Chamma preview and semantic targets use the same tested geometry as the platform-free rules data.

4

Grandma state system

Idle, attention, interaction, and reaction states are available through a typed atlas renderer and development probe.

5

Motion preferences

Cinematic travel is interruptible and has a complete immediate alternative when system reduced motion is enabled.

6

Reusable mobile foundation

Expo Router, native accessible controls, Skia scene layers, Reanimated motion, and a verified production export.
